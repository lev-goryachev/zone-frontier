# Zone Frontier

Zone Frontier is a planned strategic gameplay layer for S.T.A.L.K.E.R. GAMMA 0.9.5.

The project aims to add territory control, logistics, caravans, resource pressure, faction economy, construction, and strategic AI while keeping GAMMA responsible for survival, combat, ALife, items, and atmosphere.

Current status: documentation-first planning and early project setup.
